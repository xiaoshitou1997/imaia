imaia 数据结构 v0.2 定稿 ER 模型

17 表 · 2026-11-16 · 与 V1–V7 迁移（原地改后）同源 · 评审稿
命名铁律：实体=名词单数；关系=bind；账本=ledger；执行=run；前缀只有 im_（平台侧）/ ai_（AI 侧）； 持久配置=account、活链路=connection（运行时类）；画像挂 contact 不挂区间。
本轮删除（5）：ai_turn / ai_context_message / ai_tool_call / ai_call_log / ai_model_binding ——上下文不落库（历史从 im_message 重建）、调用审计撤、槽位改推导。
本轮改名（4）：im_member → im_conversation_contact_bind（表名两段=两个 FK，仅群会话建行）； task_definition → im_task_definition；task_run → im_task_run；insight_report → im_report； insight_member_profile → im_contact_profile（FK 改挂 contact，修退群重入孤立缺陷）。
捚除 FK 列（6）：outbound_ledger.turn_id、memory.source_turn_id、artifact.turn_id/ai_tool_call_id、 task_definition.source_turn_id、report/profile.ai_call_log_id。
替补规则：槽位推导——chat=enabled∧text入∧tool_calls；vision=enabled∧image入（无则回退 chat）； image/video=enabled∧对应 modality 出；多候选取 id 最小，换模型靠目录 enabled 控制。 历史重建——会话最近 N 条 (incoming ∨ origin='ai') ∧ kind='text'，incoming→user、outgoing→assistant。
设置三分法：基础设施=yml/环境变量；能力配置=ai_setting（四级作用域 KV）；sys_setting 暂不建。

    im_account {
        bigint id PK
        varchar platform "wechat|feishu"
        text name
        bool enabled
        jsonb config "凭据掩码外发"
    }
    im_conversation {
        bigint id PK
        bigint account_id FK
        text platform_id "平台原生会话ID"
        varchar kind "direct|group|channel"
        text title "展示名"
        text remark
        timestamptz archived_at "NULL=活动"
        timestamptz last_message_at
    }
    im_contact {
        bigint id PK
        bigint account_id FK
        text platform_id
        text display_name "平台昵称"
        text alias
        varchar kind "user|bot|system"
    }
    im_conversation_contact_bind {
        bigint id PK
        bigint conversation_id FK "仅群会话建行"
        bigint contact_id FK
        varchar role "owner|admin|member|bot"
        text display_name "群昵称快照"
        timestamptz joined_at
        timestamptz left_at "NULL=在册"
    }
    im_message {
        bigint id PK
        bigint conversation_id FK
        bigint contact_id FK "发送者"
        text platform_id "UNIQUE(会话,平台ID)"
        varchar direction "incoming|outgoing"
        varchar origin "human|ai|system"
        varchar kind "text|image|voice|video|sticker|file|rich|other"
        bool mentioned
        text body
        jsonb raw_payload "平台原文"
        bigint reply_to_message_id FK
        timestamptz occurred_at
    }
    im_attachment {
        bigint id PK
        bigint message_id FK
        varchar kind "image|voice|video|sticker|file|preview"
        text platform_ref
        text storage_ref "懒下载后回填"
        varchar status "pending|downloaded|failed|skipped"
    }
    im_inbound_ledger {
        bigint account_id PK
        text platform_message_id PK
        varchar event_kind PK
        timestamptz processed_at
    }
    im_outbound_ledger {
        bigint id PK
        bigint conversation_id FK
        text idempotency_key UK "全局唯一防重发"
        varchar source "ai_reply|task|manual|api"
        text body
        bigint artifact_id FK
        bigint message_id FK "归档回流回填"
        varchar status "pending|sent|failed|skipped"
    }
    ai_setting {
        text key PK
        varchar platform "作用域1：可空"
        bigint account_id FK "作用域2：可空"
        bigint conversation_id FK "作用域3：可空"
        jsonb value "三标识全NULL=全局"
        timestamptz updated_at
    }
    ai_provider {
        bigint id PK
        text name UK
        varchar kind "openai|tavily|other"
        text base_url
        text api_key
    }
    ai_model {
        bigint id PK
        bigint provider_id FK
        text model_key "UNIQUE(provider,model)"
        jsonb modalities_in
        jsonb modalities_out
        bool supports_tool_calls
        bool enabled "可用池=槽位推导源"
    }
    ai_memory {
        bigint id PK
        bigint conversation_id FK
        varchar kind "fact|preference|relationship|other"
        text fact
        varchar status "active|superseded|forgotten"
        bigint source_message_id FK
    }
    ai_artifact {
        bigint id PK
        bigint conversation_id FK
        varchar kind "image|video|audio|file"
        text prompt
        varchar(64) sha256
        text storage_ref
        varchar status "generated|delivered|failed"
    }
    im_task_definition {
        bigint id PK
        bigint conversation_id FK
        varchar kind "reminder|cron|report"
        varchar schedule_type "once|cron 互斥CHECK"
        text content
        text prompt
        timestamptz run_at
        text cron_expr
        timestamptz next_run_at
    }
    im_task_run {
        bigint id PK
        bigint task_id FK
        timestamptz scheduled_for "UNIQUE(task,计划点)"
        varchar status "running|sent|failed|skipped"
        bigint outbound_ledger_id FK
    }
    im_report {
        bigint id PK
        bigint conversation_id FK
        varchar period_type "week|month|year"
        date period_start "UNIQUE(会话,周期,起点)"
        jsonb stats
        text ai_report
        varchar status "stats_only|final|failed"
    }
    im_contact_profile {
        bigint id PK
        bigint conversation_id FK
        bigint contact_id FK "UNIQUE(会话,联系人)"
        text profile
        int message_count
    }

                / im_task_definition（任务）/ im_task_run（经 definition）/ im_report / im_contact_profile
                / ai_memory / ai_artifact / ai_setting（会话作用域）
im_contact 1—N im_message（发送）/ im_conversation_contact_bind（参与）/ im_contact_profile（画像对象）
im_message 1—N im_attachment；自关联 reply_to_message_id
im_task_definition 1—N im_task_run → outbound_ledger_id → im_outbound_ledger
ai_provider 1—N ai_model（槽位推导：chat/vision/image/video）
