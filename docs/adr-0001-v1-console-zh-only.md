# ADR 0001 — v1 控制台与 API 文案仅中文（i18n 双语条款豁免）

| 项 | 值 |
| --- | --- |
| 状态 | 已接受（2026-11-24） |
| 影响范围 | imaia-service 控制台 API 文案、imaia-web 界面文案 |

## 背景

团队编码规范要求用户可见文案走国际化资源，最低支持 `zh-CN`（默认）与 `en-US` 双语。
imaia 是**单用户（hub 主人）自用**的本地管理系统（PRD v0.2 非目标：多用户、公网部署），
主人为中文用户，控制台仅供本人使用。

## 决策

v1 不引入 i18n 资源骨架：后端错误/业务文案、前端界面文案直接硬编码中文，
作为对规范条款 38–40（后端）与前端条款 6 的**显式偏离**。

## 后果与回退

- 代价：若将来开放多用户或非中文使用者，需要全量补提取文案，成本与文案数量线性。
- 触发重评的条件：多用户/多租户立项、对外交付、需要 en-US 的使用场景任一出现。
- 届时的做法：后端文案迁移到 `MessageSource`（messageKey 化），前端接入既有双语骨架；
  生成方判据按 mv-coding-standards spring-guide「国际化」执行。
